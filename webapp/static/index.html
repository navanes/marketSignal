AI Support

Quote Assistant

Use the assistant to understand the form, explain quote results, troubleshoot visible errors, and prepare clean diagnostics when you need support.

What It Can Do

  • Explain each form field and tell you what is missing before a run.
  • Read latest quote results and summarize what happened.
  • Inspect screenshots and help troubleshoot visible page errors.
  • Use current form values, status text, and recent run events as context.

Buttons And Features

  • Attach Screenshot: sends the current screenshot with your question.
  • Clear Chat: resets the conversation and removes old assistant replies.
  • Troubleshoot Error: drafts a debugging prompt from the current page state.
  • Copy for Codex: copies diagnostics you can paste into the developer chat.
  • Ask Assistant: sends your question with current app context.
