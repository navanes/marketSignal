Method

How the model is built

The forecast

A learned regression model estimates the forward return for a chosen horizon from ~16 price-derived features — momentum, moving-average structure, RSI, MACD, range position, realised volatility, distance to support/resistance, and a historical-analog probability. Direction (up / down / sideways) comes from comparing that estimate to a volatility-scaled "flat" band, so a call is only made when the expected move is bigger than the noise.

The overlay

On top of the model's number, two live-only signals add a small bounded nudge: fundamentals (analyst target upside, recommendation trend, earnings-estimate revisions, growth) and news (de-duplicated, recency-weighted headline tone with event tags). The total tilt is capped at ±3 percentage points, and the model's raw call is logged alongside the adjusted one so we can measure whether the overlay actually helps.

Champion / challenger

Any new model — different features, a different algorithm — is trained walk-forward and scored by a simple +1 / −1 / 0 strategy P&L (staying flat scores zero, so it can't win by refusing to commit). It only replaces the live model if it clearly beats it out-of-sample. A gradient-boosted-tree challenger and a macro-regime feature set have both been tried and rejected under this rule.

Honesty notes

The backtest covers one broadly bullish regime and ignores trading costs. "High confidence" from earlier model versions was poorly calibrated. Live forward-testing is what settles it, and that record is still young.
